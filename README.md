# FreeNotesFX
FreeNotesFX es un gestor de notas/tareas de codigo abierto construida con JavaFX

### Idiomas
- Español (ES)
- Inglés (EN)

---
## Funcionalidades
- Añadir notas
- Editar notas
- Eliminar notas
- Guardado local
- Poner prioridades
- Poner fecha limite
- Seleccionar filtros de vista
- Cambiar de idioma
